# 모아씀 v0.1.30

- 금융앱 거래목록 사진에서 화면 상단 월과 날짜를 기준으로 거래일을 읽도록 보완했습니다. 아래쪽의 이전 달 구간이 위쪽 거래 날짜에 섞이지 않습니다.
- 취소 문구가 금액과 다른 OCR 줄에 있어도 해당 거래를 제외합니다. 달력 합계·요일·내 계좌 간 이체도 거래로 추가하지 않습니다.
- 겹치는 캡처 3장의 실기기 미리보기에서 신규 후보 12건과 사진 간 중복 7건을 확인했습니다. 금액·날짜·가맹점이 충분히 분명한 7건만 선택 가능했고, 송금 상대 2건·복권 분류 1건·네이버페이 결제처 분류 2건은 수정 확인 전 저장할 수 없었습니다.
- 배달의민족 OCR 흔들림을 표준 가맹점명으로 정리하고, 마라탕을 식비로 분류합니다. 복권 당첨 수입은 계좌이체/금융으로 오분류하지 않고 카테고리 확인을 요청합니다.
- 이미지와 OCR은 무료 한국어 ML Kit로 기기 안에서만 처리합니다. 유료 API를 호출하거나 사진을 서버로 보내지 않습니다.
- 내역 화면에서 비어 있는 달을 선택한 날짜로 바로 기록하거나 CSV를 가져올 수 있습니다.

## 검증

- `ReceiptOcrTest` 회귀 테스트에서 세 캡처의 12개 고유 거래와 7개 중복, 10월 날짜, 취소·계좌 간 이체 제외, 상호명 정규화 및 미확정 항목 차단을 확인했습니다.
- Galaxy Z Fold4에서 첨부된 3장을 직접 골라 OCR 미리보기를 확인했습니다. 화면은 `3장 · 새 내역 12건`, `중복 7건 제외`, `신규 7건 추가`로 표시됐습니다.
- 테스트 후보는 취소했고 QA 장부에는 거래를 저장하지 않았습니다. 이미지와 OCR 텍스트도 로그나 서버에 기록하지 않았습니다.
- 단말 OCR은 이미지 품질과 글자 배치의 영향을 받습니다. 결제처가 `네이버페이`만 표시된 경우 원래 가맹점을 사진만으로 알 수 없으므로 확인 후 저장하게 합니다.
