# 모아씀 v0.1.46 — 리포트와 검색을 더 잘 찾도록

## 달라진 점

- 리포트 탭에서 이전·다음 달을 바로 선택할 수 있습니다.
- 월급날 설정을 반영한 예산 주기 기준 사용률과 남은 금액을 진행 막대로 확인합니다. 목표를 초과하면 초과 금액을 보여주고, 목표가 설정되지 않았으면 같은 화면에서 설정할 수 있습니다.
- 관리 자연어 검색이 월급날에 맞춘 예산 주기, 남은 예산 이월, 사용법 질문을 더 정확히 구분합니다. 검색 결과를 고르면 설명을 먼저 보여주고 실행 버튼은 그대로 명시적으로 누르게 합니다.
- 함께 기능 미리보기에서 공동 목표 진행률과 공동 수입·생활비·고정비의 예시를 한눈에 확인할 수 있습니다. 예시는 합성 값이며, 거래는 자동 공유되지 않습니다.
- 홈 챌린지·함께 미리보기·공유 사진 용량 막대의 끝 모양과 진행률 접근성 정보를 통일했습니다.

## 검증

- Android 단위 테스트 261건 통과.
- Cloudflare Worker 테스트 23건 및 TypeScript 타입 검사 통과. Worker 코드는 이번 릴리스에서 변경하지 않았습니다.
- Galaxy Z Fold4 전체 계측 테스트 49건 통과, 1건 건너뜀(운영 Supabase 자격 증명을 사용하는 실제 로그인 E2E). 리포트 달 이동·예산 바로가기·월급날 기준 예산 사용률·잔액·초과 표시, 자연어 검색, 함께 미리보기·공유 대시보드, 업데이트 슬라이드가 포함됩니다.
- Android 단위 테스트 261건 통과. Debug lint와 Release lint-vital은 통과했으며 전체 Debug lint에는 기존 경고/정보가 남아 있습니다. Cloudflare Worker 테스트 23건과 TypeScript 타입 검사는 이번 코드에서 Worker를 바꾸지 않았지만 사전 검증으로 통과했습니다.

- 운영 거래와 Supabase 데이터는 변경하지 않았습니다. Worker·DB schema 변경이 없어 서버 배포/migration은 없습니다.
