# 모아씀 v0.1.22 — 무료 첫 실행 안내와 시스템 바 정리

- 처음 실행할 때 무료 가계부와 목표 지출, 빠른 기록, 결제 알림, AI 기능을 보여 주는 4단계 안내를 추가했습니다.
- 안내는 홈 도움말 또는 `관리 → 기능 안내`에서 다시 열 수 있습니다.
- 알림 권한이 없을 때 Android 설정으로 이동하는 버튼을 제공하고, 안내를 마친 뒤 알림 접근·앱 알림·AI 오탐 분류 상태를 한 번에 확인할 수 있습니다. 금융 알림은 자동 저장되지 않습니다.
- 상태 표시줄을 숨기지 않도록 바꾸고 홈 화면·안내·거래 입력 시트의 상단/하단 시스템 영역 여백을 확인했습니다.
- 앱 화면만 변경했습니다. Worker, Supabase 설정/데이터, Room 스키마에는 변경이 없습니다.

## 검증

- Android 단위 테스트 137개 통과
- `lintDebug`: 오류 0
- Debug, AndroidTest, Release APK 빌드 성공

- 알림 접근 권한을 포함한 시스템 권한은 테스트 중 변경하지 않았고, Weeple 앱의 진행 중 안내 화면도 조작하지 않았습니다.
