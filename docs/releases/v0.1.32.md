# 모아씀 v0.1.32 — 무료로 함께 쓰기와 매월 저축

- 함께 화면에서 무료 시작과 선택 공유를 더 분명히 안내합니다. 개인 거래는 자동 공유되지 않습니다.
- 함께 쓰는 방식에 `매월 저축`을 추가했습니다. 선택한 달의 공동 목표액과 현재 모은 금액을 합산해 진행 막대로 보여줍니다. 모은 금액은 두 사람이 공동 목표에서 직접 관리하며, 은행 자동이체나 실제 송금은 하지 않습니다.
- 업데이트 안내에 실제 Galaxy Z Fold4의 모아씀 함께 화면 캡처를 넣었습니다.
- Supabase 운영 프로젝트에 승인된 migration `202610080002`–`202610100005`를 적용했습니다. 공동 목표 진행액, 공동 재정, 설정/연결 해제와 저축 방식 저장을 위한 스키마·정책만 추가했으며 개인 거래를 업로드·삭제하지 않았습니다.
