# 모아씀 v0.1.45 — 예산을 빠르게 고르고 관리 메뉴를 정돈

월 목표를 빠르게 정하고, 관리 메뉴와 인사이트 도구를 더 쉽게 찾도록 정리했습니다.

## 달라진 점

- 월 목표 지출 수정 창에서 10만·30만·50만·100만·300만 원을 바로 선택할 수 있습니다. 직접 입력도 유지합니다.
- 관리 화면에서 백업·계정·화면 설정을 `앱과 데이터` 아래에 모아 필요할 때 펼칩니다. 검색으로 기능을 찾을 수도 있습니다.
- 앱 업데이트 확인 카드는 접기와 상관없이 계속 보여서 새 버전을 확인하는 동선은 유지됩니다.
- 펼침/접힘 애니메이션은 모션 줄이기 설정을 따릅니다.
- 취소로 제외된 거래의 사진은 목록 창을 닫지 않고 같은 창에서 확인합니다. 목록으로 돌아오거나 그 자리에서 후보로 복원할 수 있습니다.
- 인사이트의 무지출 챌린지·구독/고정비 레이더·연말정산 도우미를 각각 눌러 바로 열 수 있습니다. 고정비 바로가기에는 등록된 활성 반복 지출 합계가 표시됩니다.

## 검증

- Android 단위 테스트 260건 통과.
- Galaxy Z Fold4 계측 테스트 43건 중 42건 통과. 실제 Supabase 계정 상태를 바꾸는 로그인 E2E 1건은 의도적으로 건너뛰었습니다.
- `lintDebug`, `lintVitalRelease`, Debug·Release APK 빌드 통과. Lint 오류 0건, 기존 경고 28건.
- Fold4의 격리된 `.qa` 앱에서 예산 프리셋 선택/저장, 관리 그룹 펼침/접힘, 인사이트 세 바로가기 연결, 새 기능 팝업의 네 장 전환, 취소된 사진 거래의 근거를 같은 창에서 보고 목록 복귀/복원하는 흐름을 확인했습니다. 캡처에는 합성 데이터만 사용했으며 개인용 앱 데이터는 사용하지 않았습니다.
- 기능을 사용할 때 추가 권한, 계정, 유료 API 또는 서버 migration은 필요하지 않습니다.
