# 모아씀 v0.1.44 — 홈 요약 정리

홈 첫 화면의 중복 요약을 줄이고 무지출 챌린지 상태를 정확히 보여줍니다.

![Fold4 QA 홈 화면 캡처](https://raw.githubusercontent.com/blossom0948/gagebu2/main/app/src/main/res/drawable-nodpi/whats_new_0_1_44_compact_home.jpg)

## 달라진 점

- `오늘 지출`은 오늘·이번 주 요약 카드에 이미 포함되어 있어, 별도의 오늘 소비 요약 카드는 새 기본 홈에서 숨깁니다. `관리 → 홈 카드 구성`에서 다시 표시할 수 있습니다.
- 홈 카드 구성과 전체 백업/복원이 선택 상태를 유지하도록 조정했습니다. 이전에 직접 설정한 카드나 백업 데이터의 선택은 계속 인식합니다.
- 무지출 챌린지가 시작되기 전인데도 지출이 있었다고 표시하던 문제를 고쳤습니다. 시작 예정일, 오늘 지출, 연속 무지출, 목표 달성을 구분합니다.
- 목표 지출 진행 막대와 홈의 오늘·이번 주 소비 요약은 유지합니다.

## 검증

- Galaxy Z Fold4의 격리된 `.qa` 앱에서 합성 장부와 월 목표를 이용해 홈을 렌더링하고 화면을 캡처해 확인했습니다. 실제 개인 거래는 사용하지 않았습니다.
- Android 단위 테스트 259건 통과.
- Galaxy Z Fold4 계측 테스트 39건 중 38건 통과, 원격 Supabase 실계정 인증 테스트 1건은 계정 상태를 건드리지 않도록 제외했습니다.
- `lintDebug`, `lintVitalRelease`, Debug·Release APK 빌드 통과. Lint 오류 0건, 기존 경고 28건입니다. 전체 태스크를 한꺼번에 실행한 첫 시도는 Lint 분석기의 FIR 내부 예외로 실패했지만, Lint 단독 재실행은 통과했습니다.
- APK 앱 ID `com.moasseum.app`, versionCode `44`, versionName `0.1.44`이며 기존 공개 APK와 같은 서명 인증서 지문을 확인했습니다.
