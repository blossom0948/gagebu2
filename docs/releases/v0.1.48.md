# 모아씀 v0.1.48 — 대표 사진 선택과 공휴일 달력

## 달라진 점

- 함께 화면에서 이미 공유 앨범에 있는 사진을 골라 상단 대표 사진으로 지정합니다. 선택은 두 멤버 설정에 동기화됩니다. 새 사진을 선택·업로드하거나 개인 사진을 공유하지 않습니다. 최신 공유 사진으로 되돌릴 수 있으며, 대표 사진을 앨범에서 삭제하면 선택도 자동 해제됩니다.
- 내역 달력은 토요일을 파란색, 일요일·공휴일을 코랄색으로 표시합니다. 선택한 공휴일 이름을 달력 안에서 바로 읽고, 날짜 접근성 이름에도 포함합니다.
- 공휴일 표는 최근 연도 날짜표와 매년 같은 양력 날짜를 조합합니다. 2027·2028은 한국천문연구원의 공식 발표 전 공개된 사전 자료를 바탕으로 하므로, 공식 달력 발표 뒤 갱신이 필요합니다. [한국천문연구원 2027 자료](https://astro.kasi.re.kr/kor/life/post/calendarData?search_year=2027), [2028 자료](https://astro.kasi.re.kr/kor/life/post/calendarData?search_year=2028).

## 데이터·서버 변경

- 운영 `moasseum`의 `shared_ledger_settings`에 nullable UUID `featured_memory_photo_id`를 추가했습니다. 기존 기록을 고치지 않고 새 기본값은 `null`입니다. `information_schema.columns`에서 타입 `uuid`, nullable `YES`를 확인했습니다.
- 관계 설정 API는 대표 사진 ID만 저장하고, 실제 사진 객체는 기존 공유 앨범에 둡니다. Cloudflare Worker·개인 거래·계정 권한은 변경하지 않았습니다.
