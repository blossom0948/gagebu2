# 모아씀 v0.1.28

- 금융앱 캡처를 여러 장 선택해 신규 거래를 모두 검토하고 저장할 수 있습니다. 장부에 이미 있거나 서로 다른 캡처에 겹친 거래는 제외합니다.
- 사진 거래는 가맹점·수입/지출·금액·날짜·카테고리·결제 수단·메모를 수정할 수 있습니다. 확인이 필요한 낮은 확신 거래는 수정 확인 전 저장할 수 없고, 사진을 더 선택해도 편집값과 선택 상태가 유지됩니다.
- 카페·올리브영·구독 서비스 등의 자동 카테고리 분류를 보완하고, 계좌/승인/주문 번호와 예정 금액이 거래로 잡히지 않도록 했습니다.
- 연말 자료 정리에 월별 수입·지출 흐름과 카테고리·결제수단별 합계/건수를 추가했습니다. 이체는 수입·지출 합계에서 제외하며 세액·공제·환급액은 계산하지 않습니다.
- 하단 메뉴 선택 반응을 가볍게 다듬었습니다. 기존 글꼴 크기와 모아씀 테마는 유지합니다.
- 업데이트 안내에 사진 가져오기와 연말 자료 정리의 실제 QA 화면을 슬라이드로 넣었습니다.

## 검증

- Android 단위 테스트 169개 통과
- `:app:lintDebug` 통과: 오류 0, 경고 24
- Galaxy Z Fold4 / Android 16 계측 테스트: 12개 통과, 원격 Supabase 로그인 1개는 자격 증명 테스트를 하지 않아 건너뜀
- 실제 Fold 커버 화면에서 QA 전용 앱으로 캡처 2장을 선택: 신규 거래 2건 보존, 기존/교차 캡처 중복 2건 제외, 저장 후 합계·카테고리 반영 확인
- QA 합성 거래만 사용했습니다. 개인용 앱 장부는 변경하지 않았습니다.
- Supabase/Worker 설정과 Room 스키마는 변경하지 않았습니다.
