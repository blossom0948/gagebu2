# 모아씀 v0.1.54 — 빠른 기록, 더 정확한 사진 방향

## 이번에 바뀐 부분

- **AI 창 뒤의 메뉴 잠금**: 팝업이 열린 동안 하단 탭과 추가 버튼이 함께 어두워지고, 눌러도 다른 화면이나 입력창이 열리지 않습니다. 보조기술에서도 두 동작을 비활성 상태로 안내하며, 바깥을 누르거나 닫히는 중 뒤로가기를 연속 입력해도 화면 아래로 동작이 새지 않습니다.
- **예산 기간을 홈에서 확인**: 큰 지출 합계에 급여일 기준 예산 기간 라벨을 표시해 달력 월 합계와 구별합니다.
- **이전 거래 추천 개선**: 가맹점 이름의 앞부분이 맞는 기록을 먼저 보여줍니다. 고르면 금액·분류·결제수단을 채우고 거래일은 오늘 입력값을 유지합니다.
- **앱 아이콘 빠른 입력**: 홈 화면에서 모아씀 아이콘을 길게 눌러 `지출 추가` 또는 `수입 추가`를 선택하면 해당 입력창이 바로 열립니다. 거래 저장은 직접 확인해야 합니다.
- **사진 방향·개인정보 처리 보강**: 선택한 공유 사진의 EXIF 회전·거울 방향을 모두 반영하고 GPS 같은 EXIF 정보를 제거한 JPEG로 변환합니다. 변환은 기기에서 처리합니다. 이번 QA는 합성 이미지와 앨범 UI만 사용했고 사진을 서버로 올리지 않았습니다.
- **내역 빈 화면 정리**: CSV 가져오기 버튼이 상단과 빈 화면에 중복되던 부분을 제거했습니다. 빈 화면에는 선택 날짜 추가만 남기고, 가져오기/내보내기 아이콘도 서로 다르게 표시합니다. Fold4 격리 `.qa` 실제 화면을 캡처해 업데이트 안내에 추가했습니다.

이 변경은 Weeple 공개 기능을 중복 추가한 것이 아니라, 모아씀에서 확인된 입력·화면 결함을 보완하고 Android 바로가기를 추가한 것입니다. Weeple의 다른 앱에서 모아씀으로 사진/결제 화면을 공유하는 흐름, 백업·복원, 앱 잠금, 연결 복귀 새로고침 등은 이미 구현되어 있어 이번에는 다시 만들지 않았습니다. 구독·광고·유료 크레딧은 무료 우선 원칙에 따라 추가하지 않았습니다.

## 검증

- Android 단위 테스트: 289건 통과.
- Galaxy Z Fold4 / Android 16 격리 `.qa` 계측 전체 회귀: 71건 중 70건 통과, 운영 인증 E2E 1건은 안전상 건너뜀, 실패 0건. 내역 화면 중복 버튼 및 6개 업데이트 슬라이드의 단독 계측도 통과했습니다.
- AI 모달 하단 탭·추가 버튼은 실제 터치 차단뿐 아니라 비활성 접근성 상태를, 닫히는 중 반복 뒤로가기는 Fold4 계측으로 확인했습니다.
- 가장 오래된 지원 설치 버전에서 v0.1.54로 올리는 경우까지 마지막 확인 뒤의 릴리스 기록이 누적되는지 단위 테스트로 검증했습니다.
- `lintDebug`: 오류 0건, 경고 20건, 정보 수준 권장 7건. 경고는 targetSdk 35·최신 라이브러리 권장 및 kapt 전환 권고 등이 주를 이룹니다. targetSdk/대형 라이브러리 업그레이드는 회귀 위험 때문에 이번 안정화 범위에서 바꾸지 않았습니다.
- 실제 기기에서 AI 모달, 홈, 빠른 입력 단축 주소를 확인했습니다. QA 데이터만 사용했고 거래를 저장하지 않았습니다.
- EXIF 방향 2~8 합성 이미지 검사에서 발견한 방향 5 대각선 변환 오류를 수정했습니다. 변환 결과 크기와 네 색상 영역 방향을 각각 확인했습니다.

## 남은 차이와 안전 범위

- 앱 언어는 한국어이며 Weeple의 영어·일본어·중국어 및 기존 Weple Money의 다국어 범위와 다릅니다.
- 모든 파트너 연결 화면을 두 실제 계정으로 전수 대조하거나 운영 계정 E2E를 수행한 것은 아닙니다. 전체 Weeple 기능·디자인 동등을 의미하지 않습니다.
- 사진 변환은 테스트에서 기기 내 합성 데이터만 처리했습니다. 개인 사진, 운영 앱·Weeple 데이터, 계정·서버 설정은 변경하지 않았습니다.
- Android 시스템이 요구하는 마지막 APK 설치 승인은 사용자가 직접 해야 합니다.
