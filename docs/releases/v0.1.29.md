# 모아씀 v0.1.29

- Fold 펼친 화면에 대시보드와 소비내역의 넓은 레이아웃을 추가했습니다. 소비내역에서는 달력과 거래 목록을 나란히 확인할 수 있습니다.
- 금융앱 캡처는 이미지를 서버에 보내지 않고 기기에서 OCR 처리합니다. 텍스트 순서 대신 화면의 실제 줄 배치로 금액과 가맹점을 연결하고, 달력 합계·요일·안내 배너·내 계좌 간 이동은 거래 후보에서 제외합니다.
- 여러 사진의 겹치는 거래와 장부에 이미 있는 거래를 중복 제외합니다. 중복 안내 문구도 실제 제외 기준에 맞게 정리했습니다.
- 버거킹·하이푸드 등 거래처 카테고리 분류와 입출금 상대방·금액·날짜 인식을 보완했습니다. 불확실한 후보는 검토 화면에서 확인한 뒤 저장합니다.
- 업데이트 확인 시 새 버전 안내를 표시하고, 앱 안에서 APK 다운로드 후 Android 설치 확인으로 이어지게 했습니다. Android 보안상 설치 최종 승인은 사용자가 해야 합니다.

## 검증

- Android 단위 테스트와 `:app:lintDebug` 통과
- 단위 테스트 177개 통과; `:app:assembleDebugAndroidTest` 빌드 성공
- Galaxy Z Fold4 실기기에서 금융앱 캡처 2장 OCR 확인: 신규 후보 11건, 사진 간 중복 2건 제외
- 화면 후보에서 날짜·거래처·금액·유형·카테고리를 확인하고 취소했습니다. QA 중 개인 장부에 거래를 저장하지 않았습니다.
- 달력 합계·요일 문자열·캐시백 안내 배너 및 10월 4일 계좌 간 이동 2건은 거래 후보에 포함되지 않았습니다.
- 이미지와 OCR 텍스트는 기기 밖으로 전송하지 않았습니다.
- Cloudflare Worker와 Supabase 스키마/설정은 변경하지 않았습니다.
