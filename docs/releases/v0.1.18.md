# 모아씀 v0.1.18

- 모아씀 전용 Supabase Free 서버를 연결해 이메일 로그인·회원가입·비밀번호 재설정을 활성화했습니다. 다른 프로젝트는 변경하지 않았습니다.
- 기본 이메일의 확인/재설정 링크로 앱에 돌아오는 PKCE 인증과 암호화된 인증 요청 저장을 추가했습니다. 메일은 요청한 휴대폰에서 열어 주세요.
- AI 분석·질문·문장 인식·알림 AI 판별은 로그인 후 사용합니다. 기본 수동 기록·기기 내 알림 감지는 로그인 없이 유지됩니다.
- 인증 요청이 Cloudflare 실행 환경에서 503으로 실패하던 문제를 수정하고 실제 실행 환경의 회귀 테스트를 추가했습니다.
- 기존 가계부 데이터·목표·작은 글꼴·테마와 동일 서명을 유지하는 업데이트입니다.

## 사용 방법 / 현재 제한

앱에서 `관리 → 로그인·계정 → 회원가입`을 여세요. 현재 무료 기본 메일은 Supabase 조직에 등록된 본인 이메일만 사용할 수 있고 시간당 2통으로 제한됩니다. 앱 비밀번호는 직접 정하며 Supabase 관리자 로그인과 별개입니다. 유료 서비스 가입이나 이메일 인증 해제는 하지 않았습니다.

로그인만으로 기록이 서버에 업로드되거나 공유되지 않습니다. 공동 장부·초대·기기 간 원장 동기화는 아직 제공하지 않습니다. 실제 본인 이메일의 메일 수신/링크 완료는 별도 확인이 필요합니다.

기존 앱은 `관리 → 앱 업데이트`에서 APK를 직접 받을 수 있습니다. 설치 확인은 Android 시스템 화면에서 눌러야 합니다.

검증: Android 단위 84개, 격리된 실기기 9개(실제 서버 로그인/AI 포함), Worker 10개 통과. lint 오류 0. Galaxy Z Fold4에 기존 데이터를 유지한 업데이트 설치 완료.
