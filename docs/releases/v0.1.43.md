# 모아씀 v0.1.43 — 사진 거래 취소 내역 확인

금융앱 거래내역 캡처 여러 장에서 중복과 취소 거래를 더 안전하게 걸러내고, 제외된 항목을 사진으로 확인해 되돌릴 수 있습니다.

![Fold4 QA 앱의 사진 거래 검토 화면](https://raw.githubusercontent.com/blossom0948/gagebu2/main/app/src/main/res/drawable-nodpi/whats_new_0_1_43_photo_review.jpg)

## 달라진 점

- 서로 다른 사진에 나뉘어 표시된 같은 날짜·금액·가맹점의 명시적 취소 내역도 찾아 해당 거래를 신규 후보에서 제외합니다. 취소 알림 자체는 장부에 저장하지 않습니다.
- 완료된 결제 취소·환불 영수증을 정상 지출로 가져오지 않습니다. 단순히 취소를 언급한 안내문까지 일괄 차단하지는 않습니다.
- 제외 내역은 `거래 보기`에서 확인하고 `사진 보기`로 해당 거래만 잘라낸 사진을 먼저 확인할 수 있습니다. 필요하면 원본 전체도 열 수 있습니다. 잘못 제외된 항목은 `후보로 복원`한 다음, 검토 화면의 최종 추가 버튼을 눌러야 저장됩니다.
- 취소표시 사진을 먼저 선택하고 원 거래 사진을 나중에 추가해도 취소 근거를 검토가 끝날 때까지 유지합니다.
- 사진과 OCR 결과는 무료 온디바이스 ML Kit에서 처리합니다. Gemini나 다른 서버에 금융 사진·인식 문장을 보내지 않으며 자동 저장도 하지 않습니다.

## 검증

- 제공된 거래목록 캡처 3장을 Galaxy Z Fold4에서 다시 검사했습니다. 합친 결과는 신규 후보 11건, 중복 7건 제외, 취소 1건 제외였습니다. 실제 장부가 아니라 이미지 후보 미리보기로만 검증했습니다.
- Android 단위 테스트 253건 통과. 취소 근거가 다른 사진에 있을 때의 매칭, 취소 거래와 다른 가맹점의 보존, 부호가 다른 환불, 중복 취소, 취소 영수증과 일반 안내문을 검증했습니다.
- Galaxy Z Fold4 계측 테스트 36건 중 35건 통과, 원격 Supabase 로그인 1건은 실제 계정 조작을 피하기 위해 선택 제외했습니다. 취소 거래 보기·잘린 사진 확인·후보 복원·취소 사진을 먼저 고른 뒤 다음 사진으로 이어가는 흐름을 실기기에서 확인했습니다.
- `lintDebug`, `lintVitalRelease`, Debug·Release APK 빌드 통과. 개인용 앱 `com.moasseum.app`의 설치·데이터·로그인은 변경하지 않았습니다.
