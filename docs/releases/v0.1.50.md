# 모아씀 v0.1.50 — 빠른 기록과 설정 검색 개선

## 변경 사항

- 빠른 기록 창에서 개인/함께 저장 범위와 AI/직접 입력 방식을 한 줄에서 선택할 수 있습니다.
- 빠른 기록 창을 열 때 키보드가 자동으로 올라오지 않습니다. 입력을 누르면 키보드가 열립니다.
- AI·직접·상세 입력 화면 전환을 짧은 페이드/슬라이드로 연결하고, 모션 줄이기 설정을 따릅니다.
- 관리 화면의 설정 검색을 전용 페이지로 분리했습니다. 검색할 때 원래 관리 메뉴/하단 내비게이션을 숨기고, 뒤로 돌아와도 검색어가 유지됩니다.
- 업데이트 안내에 Fold4 격리 QA에서 촬영한 실제 빠른 기록 창과 검색 결과 화면을 포함했습니다. 검색어, 결제수단 및 결과는 합성 테스트 값입니다.
