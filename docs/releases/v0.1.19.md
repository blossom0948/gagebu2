# 모아씀 v0.1.19 — 구글 로그인

- `관리 → 로그인·계정 → Google로 계속하기` 추가. 기본 브라우저에서 계정을 선택한 뒤 PKCE로 앱에 돌아옵니다.
- Google/Supabase 서버 연결 완료. 현재 본인용 Testing 설정이며 승인한 소유자 계정 하나만 허용 목록에 등록했습니다. 별도 이메일 가입 인증 메일이나 SMTP 구매 없이 구글 로그인 흐름을 사용합니다.
- 이메일·기본 프로필만 요청하며 Gmail·Drive·가계부 접근은 요청하지 않습니다. Google 비밀 키는 서버에만 저장합니다.
- 기존 이메일 로그인·비밀번호 복구·기본 기록·로컬 알림 감지를 유지합니다. 전역 글자 크기·민트 테마·Room 스키마·앱 ID·서명 키는 바꾸지 않았습니다.
- 손상된 인증 요청 정리 시 예외를 처리하고 취소/만료/잘못된 반환/재사용 회귀 테스트를 추가했습니다.
