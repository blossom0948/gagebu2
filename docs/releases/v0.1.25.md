# 모아씀 v0.1.25

- 대시보드·소비내역·함께·관리의 선택된 하단 메뉴를 다시 누르면 맨 위로 이동합니다.
- 함께 장부 화면에서 인터넷 연결이 끊겼다가 복구되면, 로그인된 공유 장부를 자동으로 새로고침합니다. 오프라인 상태에는 재연결 후 동기화 안내를 표시합니다.
- 업데이트 안내에 실제 Galaxy QA 앱 화면 캡처와 기능 설명을 슬라이드로 추가했습니다.

## 검증

- Android 단위 테스트 153개 통과, `lintDebug` 통과
- Galaxy Z Fold4 / Android 16 계측 테스트 통과. 실제 Supabase 로그인 테스트는 전용 QA 자격 증명이 없어 건너뜀
- Debug, AndroidTest, Release APK 빌드 성공
- Galaxy Z Fold4의 QA 패키지(`com.moasseum.app.qa`)에서 대시보드와 함께 화면을 확인하고 실제 캡처를 업데이트 안내에 사용했습니다.
- 기존 개인용 패키지(`com.moasseum.app`)와 그 데이터를 QA 과정에서 변경하지 않았습니다.
