# 모아씀 v0.1.56

## 바뀐 부분

- **테마를 직접 선택**: 관리 → 앱과 데이터 → 테마 설정에서 기기 설정·라이트·다크 모드와 모아씀 민트·오션 블루·라벤더·웜 샌드 색 팔레트를 고릅니다. Android 12 이상은 배경화면 색도 선택할 수 있습니다.
- **기록은 그대로**: 테마 변경은 수입·지출 의미 색이나 거래를 바꾸지 않습니다. 전체 백업·복원에도 화면 모드와 색 선택이 포함됩니다.
- **Google Play 사전 준비**: Play용 별도 빌드에서 APK 자체 설치 권한을 제외하고 API 36 매니페스트 검사를 추가했습니다. Play Console 제출·게시, 업로드 키, 스토어 정책 검토는 완료하지 않았으며 이번 배포는 기존 무료 GitHub APK입니다.

## 검증

- Debug 단위 테스트 296건 통과, Fold4 / Android 16 격리 `.qa` 계측 75건 중 74건 통과·실패 0·운영 로그인 E2E 1건 skip.
- `:app:check`, `lintDebug`(오류 0·경고 34·힌트 7), Release APK 빌드 및 Play 병합 매니페스트 검사 통과.
- 기기 검사는 개인용 앱이 아닌 격리 `.qa` 패키지와 합성 UI만 대상으로 합니다.
- 사진 인식은 기존처럼 기기 안에서 처리합니다.

## Weeple 비교 범위

이번 변경은 모아씀의 색상·화면 모드 선택과 Play 빌드 분리를 추가한 것입니다. Weeple과 전체 기능·화면 동등성을 의미하지 않습니다. 전역 다국어 UI, Weeple AI의 모델·분석 범위, 두 실제 계정의 모든 파트너 화면 전이는 여전히 남은 차이 또는 미검증 항목입니다. 자세한 내용은 [Weeple 비교 진행 보고서](../../WEEPLE_PARITY_PROGRESS_2026-10-08.md)를 참고하세요.
