# 모아씀 v0.1.41 — 관리 메뉴 다시 찾기

무료 업데이트입니다. 관리 검색을 다시 써도 검색어 원문이 최근 기록으로 남지 않도록 구성하고, Fold4 QA 앱에서 실제 화면을 캡처했습니다.

![관리 검색창의 최근 실행 메뉴 칩](https://raw.githubusercontent.com/blossom0948/gagebu2/main/app/src/main/res/drawable-nodpi/whats_new_0_1_41_recent_search.jpg)

## 최근 찾은 메뉴

- 관리에서 기능을 실제로 실행하면 최근 메뉴 최대 5개를 검색창 아래 칩으로 보여줍니다.
- 칩을 누르면 바로 이동하지 않고 검색 결과와 기능 설명을 다시 펼칩니다. `예산 수정`, `알림 권한 설정`처럼 표시된 동작 버튼을 눌러야 실행됩니다.
- 최근 목록에는 기능 ID만 기기 안에 저장합니다. 검색어 원문은 최근 메뉴 기록에 저장하지 않으며, `지우기`로 목록 전체를 비울 수 있습니다.
- 입력 중인 검색어와 AI 의미 검색은 기존처럼 각각 사용자가 관리합니다. AI 검색은 사용자가 버튼을 눌렀을 때만 동작합니다.

## 검색 품질

- 관리 화면의 실제 메뉴 검색 카탈로그를 별도 정의로 분리하고, 36개 메뉴 제목과 모든 별칭을 테스트합니다.
- “카드 대금 언제 나가?”, “감지된 알림 한 번에 지우기”, “원화 말고 달러로 보고 싶어” 등 실제 사용 문장을 추가 검증했습니다.
- 표시 통화 검색 결과에 참고 환율은 화면 표시만 바꾸며 장부와 예산은 원화로 저장된다는 범위를 밝혔습니다.
