# 모아씀 v0.1.49 — 예산 기간과 업데이트 이력 안내

## 예정된 변경

- 홈에서 선택한 연·월과 급여일 기준 예산 기간을 분리해 표시합니다.
- 과거 달을 보는 동안 오늘·이번 주·무지출 챌린지처럼 현재 날짜 기준인 카드를 숨겨 기간이 다른 수치가 섞이지 않게 합니다.
- 홈 예산 요약의 수입 합계를 지출과 같은 예산 기간으로 계산합니다.
- 예산 초과 시 남은 금액이 0원으로 보이던 요약을 실제 초과액으로 바꾸고, 진행 막대에 접근성 진행률을 제공합니다.
- 과거·미래 예산 주기에는 현재 시점의 예상 지출이나 남은 일수를 표시하지 않아 기간 문구를 정확하게 유지합니다.
- 홈의 목표 지출을 누르면 관리 첫 화면에서 다시 찾지 않고 예산 편집 창으로 바로 엽니다.
- 예산 요약은 급여일 주기, 카테고리 TOP은 선택한 달력 월 기준임을 제목과 `월 한도` 표기로 구분합니다.
- 인사이트·리포트에서 달력 월 지표와 급여일 예산 잔액을 각각 표시하고, 종료된 예산 주기의 실제 지출을 미래 예상처럼 부르지 않습니다. 인사이트의 반복 관리 바로가기를 정리합니다.
- 알림함의 예산 절반·초과 알림도 달력 월이 아닌 급여일 기준 기간으로 계산합니다. 현재 날짜 뒤의 거래나 해당 기간 밖 거래는 미리 계산에 넣지 않습니다.
- 업데이트 팝업은 사용자가 마지막으로 확인한 버전 이후에 나온 모든 버전의 신기능을 오래된 순서로 보여줍니다. 한 번 확인한 버전의 내용은 다음 업데이트에서 반복하지 않습니다.
- 공개된 v0.1.1, v0.1.2, v0.1.4–v0.1.49의 각 릴리스 요약을 연결했습니다(v0.1.3은 공개 릴리스가 없습니다). 과거에 실제 캡처 이미지가 보존되지 않은 버전은 이미지를 새로 꾸며내지 않고 요약 카드로 표시합니다.

## 검증

- Android 단위 테스트 278건 통과(실패/오류 0), `lintDebug`, `compileDebugAndroidTestKotlin` 통과.
- Galaxy Z Fold4 / Android 16에서 `.qa` 계측 테스트 57건 중 56건 통과, 원격 Supabase 계정 테스트 1건 건너뜀, 실패 0건. 업데이트 팝업이 v0.1.47 이후 v0.1.48의 두 항목과 v0.1.49를 순서대로 보여주고 이전 버전은 제외하는지 확인했습니다. 초기 버전 요약 카드도 실기기에서 표시를 확인했습니다.
- 같은 실기기에서 과거 예산 주기 라벨, 예산 초과액, 월 카테고리 기준, 인사이트·리포트 기간 구분도 검증했습니다.
- v0.1.49 홈 캡처는 합성 데이터가 없는 격리 `.qa` 화면에서 생성해 업데이트 팝업 이미지로 포함했습니다.
- 운영 앱, 개인 장부, Weeple 앱 데이터, 계정, Supabase/Worker 설정과 개인 사진은 변경하지 않았습니다.
