# 모아씀 v0.1.34 — 거래 기록과 계정 관리 보강

- 외화 거래를 거래일의 무료 일일 참고 환율로 원화 환산하고, 원래 금액·적용 환율·환율 기준일을 함께 저장합니다. 참고 환율은 실제 카드사 청구액과 다를 수 있습니다. [Frankfurter API](https://frankfurter.dev/)
- 외부 입금은 연결한 계좌 잔액에만 더하고 수입·예산 합계에서는 제외합니다. 계좌를 보관하면 과거 거래 연결을 유지합니다.
- 할부 총액 수정 시 회차별 금액을 다시 배분하고, 일시불 전환과 전체 회차 삭제를 관리 화면에서 지원합니다.
- 빠른 기록 추천을 항목별로 숨길 수 있습니다.
- 로그인 계정 영구 삭제는 서버 RPC로 처리합니다. 개인 장부는 기기에 남고, 공동 장부는 다른 구성원이 있으면 그 구성원에게 소유 자료를 넘겨 보존합니다. 계정 삭제는 실제 실행하지 않았습니다.
- 공유 자료에 외화 원금·환율·기준일을 보존합니다. 공유 E2E는 두 개의 합성 로그인과 격리된 메모리 서버로 선택 공유, 왕복 동기화, 외화 메타데이터, 제3 계정 차단을 검증합니다. 실제 두 사용자의 운영 OAuth/RLS E2E는 이번 검증에서 실행하지 않았습니다.
- 대시보드·소비내역·관리·계좌·거래 입력·함께 화면을 Fold4에서 확인했습니다. 캡처 기준 시스템 바와 하단 메뉴에 콘텐츠가 겹치지 않았고, 다이얼로그의 스크롤 및 페이지 전환도 확인했습니다. 업데이트 안내 이미지는 QA 앱에서 캡처한 실제 앱 화면입니다.
