# 모아씀 v0.1.39 — 화면 표시 통화

무료 개인 업데이트입니다. 아래 그림은 Fold4의 격리된 QA 앱에서 실제 표시 통화 선택 창을 캡처한 것이며, 실제 계정·거래 자료는 들어 있지 않습니다.

![Fold4 QA 앱의 실제 표시 통화 선택 창](https://raw.githubusercontent.com/blossom0948/gagebu2/main/app/src/main/res/drawable-nodpi/whats_new_0_1_39_currency.png)

## 화면 금액을 다른 통화로 보기

- 관리 → 앱과 데이터 → 표시 통화에서 KRW, USD, JPY, EUR, TWD, SGD를 선택할 수 있습니다.
- 홈, 내역, 계좌, 함께, 관리와 거래 검토 화면의 원화 금액을 선택한 통화로 환산해 표시합니다.
- 무료 일일 참고 환율은 Frankfurter에서 가져옵니다. 최근 7일 안의 환율만 표시 계산에 사용하며, 환율을 받지 못했거나 날짜가 오래되면 원화 금액으로 돌아갑니다.
- 원장 거래, 예산 목표, 계좌 잔액과 공동 장부의 저장값은 변경하지 않습니다. 설정 백업에는 통화 선택만 포함하고, 환율은 복원 후 다시 조회합니다.
- 이 기능은 앱 언어를 바꾸지 않습니다. 앱 문구와 AI 처리·CSV/PDF 내보내기는 기존처럼 한국어·원화 기준입니다. 외화로 실제 결제한 거래 입력은 기존처럼 거래 통화와 거래일 환율을 별도로 기록합니다.
