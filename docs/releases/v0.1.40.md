## 관리 메뉴, 말하듯 찾아요

- “생활비가 얼마나 남았지?”, “알림 감지 어디서 켜?”처럼 표현해도 예산·권한·알림·계정·백업 등 메뉴를 검색합니다. 키워드·띄어쓰기·가벼운 오타를 기기 안에서 먼저 비교해 바로 결과를 보여줍니다.
- 결과를 눌러도 곧바로 화면이 바뀌지 않습니다. 검색 결과 안에서 기능 설명을 확인하고, 실제 동작을 나타내는 버튼을 눌러야 설정을 열거나 내보내기를 실행합니다.
- 더 넓은 의미로 찾고 싶을 때 로그인 후 `AI로 의미 검색`을 직접 누르면, 검색어와 앱 메뉴 ID·제목·키워드를 인증된 Gemini 검색 경로로 보냅니다. 거래 목록이나 계좌 잔액은 보내지 않습니다. 키워드 검색은 로그인이나 AI 서버 없이 계속 쓸 수 있고 AI 실패 시에도 결과가 유지됩니다.
- Google은 무료 Gemini API 입력을 제품 개선에 사용할 수 있고 사람이 검토할 수도 있다고 안내합니다. [Google Gemini API 약관](https://ai.google.dev/gemini-api/terms?hl=en). AI 검색 입력에 거래 내용·계좌 정보 등 민감한 정보를 넣지 마세요. 사용하지 않으면 AI 버튼을 누르지 않아도 됩니다.
