# 모아씀 v0.1.23 — AI 여러 거래 처리

- `+ → 문장으로 여러 건 처리`에 AI 해석을 연결했습니다. 여러 거래 추가 후보를 만들고, 개인 거래의 수정·삭제 대상을 찾는 작업을 한 문장으로 요청할 수 있습니다.
- 추가는 항목별로 확인·수정한 뒤 저장합니다. 수정·삭제는 기기 안의 개인 거래만 대상으로 미리 보여 주며, 사용자가 행을 선택해야 반영됩니다. 삭제는 한 번 더 확인합니다. 공유 거래·할부 묶음·이체는 일괄 변경 대상에서 제외합니다.
- 거래 행 자체는 AI 서버에 보내지 않습니다. AI에는 사용자가 입력한 문장만 전송하고, 검색·수정·삭제 대상 매칭은 기기에서 처리합니다.
- 함께 화면 기념일에 `D-Day`/`D-n`을 표시하고, 공동 장부 조회가 페이지 단위로 이어지도록 했습니다.
- 인증이 필요한 AI Worker `/v1/parse-batch-command`를 배포했습니다. 인증·응답 검증·요청 제한을 유지합니다.
