# 모아씀 v0.1.31

- 카카오 로그인을 모아씀 전용 Supabase에 연결했습니다. 닉네임과 프로필 사진은 선택 동의이며, 이메일 없이 로그인할 수 있습니다. 현재 Kakao 앱 권한에 이메일이 없어 이메일 범위는 요청하지 않습니다.
- 사진 거래 가져오기에서 행별 `사진` 버튼으로 해당 거래 부분만 확인할 수 있습니다. 확인이 필요한 거래도 선택·수정할 수 있고, 중복 후보 제외와 여러 장 동시 가져오기를 유지합니다.
- 앱 내 업데이트 창에 원형 다운로드 진행률과 삼성 보안 안내를 추가했습니다. Android의 마지막 설치 승인과 출처 허용은 사용자가 해야 합니다.

## 검증

- Android 단위 테스트 190개 통과, `lintDebug`, Debug/Release APK 빌드 성공.
- Galaxy Z Fold4(Android 16) 계측 테스트 14개 완료: 원격 실계정 인증 1개는 계정 생성 방지를 위해 건너뛰었으며 나머지는 통과했습니다.
- QA 앱에서 Kakao 로그인 버튼이 서버 설정에 따라 활성화됨을 확인했습니다. 실제 Kakao 동의 제출이나 운영 계정 생성은 하지 않았습니다.
- Supabase의 Kakao 제공자·이메일 없는 계정 허용 및 Kakao 콜백 주소를 확인했고, 기존 Google 로그인은 그대로 활성화되어 있습니다.
- 사진은 기존처럼 기기 안에서 OCR 처리합니다. 이번 변경은 Supabase/Room 스키마나 AI Worker를 바꾸지 않습니다.
