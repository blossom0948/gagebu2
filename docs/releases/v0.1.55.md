# 모아씀 v0.1.55

## 바뀐 부분

- **거래처 추천을 바로 선택**: 거래처 입력 중 과거 개인 거래 후보가 키보드 위 팝업으로 뜹니다. 누르면 가맹점·금액·분류·결제수단을 한 번에 채웁니다. 추천 UI는 Galaxy Z Fold4의 격리 `.qa` 앱에서 합성 데이터로 캡처했습니다.
- **설정 검색이 덜 가려져요**: 최근 항목·검색 제안·기능 결과를 고르면 키보드를 내려 상세 설명과 명시적 실행 버튼을 볼 수 있습니다.
- **AI 창 전환 안정성**: 열기와 닫기 모션을 한 전환 흐름으로 관리하고, 팝업이 완전히 펼쳐지기 전에는 메뉴 터치와 접근성 실행을 막습니다. 닫히는 중 Reduce Motion이 바뀌어도 창이 겹치거나 남지 않습니다.

## 확인

- Android 단위 테스트 289건 통과.
- Galaxy Z Fold4 / Android 16 `.qa` 계측 72건 중 71건 통과, 실패 0건. 운영 Supabase 로그인 E2E 1건은 별도 운영 인증을 사용하지 않아 건너뛰었습니다.
- `lintDebug`, `lintVitalRelease`, 서명 APK 빌드 통과.
- 사진 분석은 계속 기기 내에서만 처리합니다. QA는 합성 거래만 사용했고 개인 앱·Weeple 데이터와 운영 계정/서버 설정은 건드리지 않았습니다.

## 범위

이번 업데이트가 Weeple과 전체 기능·화면·애니메이션 동등을 뜻하지는 않습니다. 기존 비교에서 확인한 다국어와 파트너 실계정 전이 등은 여전히 별도 미검증 항목입니다. 애니메이션 참고 기준은 [Apple HIG Motion](https://developer.apple.com/design/human-interface-guidelines/motion), [Material 3 Motion](https://m3.material.io/styles/motion), [Samsung One UI Motion](https://developer.samsung.com/one-ui/motion/basic.html)입니다.
