# 모아씀 v0.1.33 — 홈 화면 빠른 기록

- 홈 화면 위젯에 `지출`과 `수입` 버튼을 추가했습니다. 누르면 해당 유형을 선택한 거래 입력 화면이 바로 열립니다. 저장 전에 내용을 확인할 수 있습니다.
- AI 알림 판별의 외부 전송 범위와 선택 공유 자료의 처리 위치를 개인정보처리방침에 맞게 정정했습니다. 위젯 미리보기는 앱의 실제 위젯 레이아웃과 동일한 버튼·색상·문구를 사용합니다.
