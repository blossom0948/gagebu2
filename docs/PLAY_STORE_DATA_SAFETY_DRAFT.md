# Google Play Data safety 작성 전 검토 초안

상태: 코드 기준 사전 조사 메모이며 Play Console에 제출한 답변이나 법률 검토 결과가 아닙니다. 기준일 2026-10-15. 실제 SDK·서버 운영 설정, 보존 기간, 제3자 위탁 조건을 확인하기 전에는 아래 분류를 최종 선언으로 복사하지 마세요.

Google Play는 앱뿐 아니라 포함된 라이브러리/SDK가 기기 밖으로 보내는 데이터도 고려하도록 안내합니다. 잠깐 처리하고 폐기하는 데이터도 폼 작성 범위에서 판단해야 합니다. [Data safety 안내](https://support.google.com/googleplay/android-developer/answer/10787469?hl=en)

## 코드에서 확인한 흐름

| 데이터·기능 | 코드에서 관찰한 처리 | Play 폼 작성 전 확인 |
| --- | --- | --- |
| 이메일·인증 제공자 계정 식별자 | Supabase 로그인/세션과 계정 관리를 위해 서버로 전송 | Supabase Auth의 저장·로그·보존기간, Google/Kakao 공급자에서 앱으로 전달되는 실제 필드와 계정 삭제 완료 범위 |
| 개인 거래·예산·계좌·메모 | 기본적으로 기기 로컬 Room/DataStore에 저장. 앱의 일반 로그인만으로 전체 개인 거래를 올리지 않음 | OS 백업, 사용자가 만든 백업 파일, 기기 진단 로그와 예외적인 전송 경로를 별도 검토 |
| 공유한 재정 정보 | 사용자가 고른 거래, 공동 목표·예산·재정 항목만 Supabase 공동 장부로 전송 | 금융 정보 분류와 서비스 제공자/공동 사용자 공유 구분, RLS·삭제·탈퇴 후 남는 항목 및 보존 정책 |
| 사진·이미지 | 거래 사진 선택/OCR은 앱 코드에서 로컬 처리. 한국어 OCR 의존성 `com.google.mlkit:text-recognition-korean`은 번들 모델 계열. 별도 커플 앨범 기능에서 사용자가 고른 사진은 EXIF 제거·JPEG 재인코딩 후 Supabase Storage에 저장 | 앨범 업로드는 사용자 선택 기반으로 설명. Storage 백업·삭제·보존/위탁 조건과 공유 멤버 접근을 확인. ML Kit의 번들 모델과 Play Services 모델을 혼동하지 않음 |
| 직접 입력한 AI 문장·질문 | 사용자가 AI 동작을 실행하면 입력과 기능별 필요한 기준일/시간대 또는 거래 집계가 인증된 중계 서버를 거쳐 Gemini로 전달될 수 있음. 거래 원장 전체를 보내는 것은 아님 | Worker 접근/요청 로그, Gemini API 처리·보존 약관, 무료/유료 API 데이터 사용 조건, 전달 필드별 최소화와 목적 분류 |
| 금융 앱 알림 텍스트 | 알림 읽기 권한은 사용자가 Android 설정에서 허용해야 함. AI 판별은 별도 설정이 기본 꺼짐이며, 켠 경우 기기 1차 필터를 통과한 알림 앱 이름/제목/내용을 판별 서버에 보냄 | 메시지/금융 정보 등으로 분류할지, Gemini 처리·로그·보존, UI의 선택 동의와 Data safety 목적을 확인 |
| 자연어 관리 검색 | 사용자가 AI 검색을 실행한 경우 검색어만 중계 서버에 전달. 거래 내역·계좌 잔액을 검색 payload에 넣지 않는 구현 | 검색어가 개인·금융 내용을 포함할 수 있다는 고지, Worker/Gemini 로그·보존 조건 |
| 환율·업데이트 확인 | Frankfurter 환율과 GitHub 릴리스 조회를 위해 통화·날짜 또는 앱 버전 등 요청이 외부 서비스로 전달될 수 있음 | 각 서비스의 접속 로그(IP 등), 실제 전송 파라미터 및 Data safety 분류를 네트워크 검사로 확인 |
| 광고·분석 SDK | 앱 직접 의존성 목록에서 광고·분석 SDK를 찾지 못함 | Play SDK Index와 릴리스 AAB의 전체 전이 의존성·manifest를 검사하기 전 “수집 없음”으로 확정하지 않음 |

Google ML Kit 공식 문서에서 `com.google.mlkit:text-recognition-korean`은 모델을 앱에 정적으로 포함하는 번들 방식으로, Play Services를 통한 동적 다운로드 라이브러리와 구분됩니다. 앱은 OCR에 원본 이미지를 입력하지만 이 코드 경로는 결과를 기기에서 처리하고 Gemini로 보내지 않습니다. [ML Kit Android 텍스트 인식](https://developers.google.com/ml-kit/vision/text-recognition/v2/android)

## 초안 분류 후보 — 아직 제출하지 않음

- 개인 정보: 이메일 주소, 사용자 ID/인증 식별자.
- 금융 정보: 사용자가 장부에 넣거나 AI에 입력하는 거래/지출 정보, 선택 공유한 공동 재정 정보.
- 사진 및 동영상: 커플 앨범에 사용자가 직접 올린 사진. 거래 사진 OCR은 앱 코드상 서버 업로드와 별도 경로.
- 앱 활동/사용자 생성 콘텐츠: AI 문장·질문·검색어, AI 알림 판별을 켠 경우 금융 앱 알림 텍스트.
- 위 분류의 “수집”, “공유”, “선택/필수”, 목적, 암호화 및 삭제 답변은 Google의 정의와 각 처리자의 계약·운영 설정을 대조한 뒤 확정해야 합니다. 특히 인증 제공자/AI 처리자가 서비스 제공자로 동작하는 경우에도 Google 폼의 제3자 공유 기준을 확인해야 합니다.

## 공개 전 막아야 할 확인 항목

1. Play 배포 AAB의 모든 직접·전이 SDK, 권한, manifest metadata와 SDK Index 검토.
2. Supabase Auth/DB/Storage, Cloudflare Worker, Gemini의 운영 로그·보존·삭제/백업 정책을 서비스별로 확인하고 개인정보처리방침과 일치시킴.
3. 공유 장부의 연결 해제·한 멤버 탈퇴·계정 삭제 시 공동 소유 자료가 남는 범위를 결정·고지하고 실제 서버 동작으로 검증.
4. 앱 내 계정 삭제 동작은 있으나 Play 등록용 외부 삭제 요청 페이지는 아직 없음. 사용자가 앱을 열 수 없어도 접근 가능한 공개 웹 경로가 필요합니다. [Play 계정 삭제 요건](https://support.google.com/googleplay/android-developer/answer/13327111?hl=en)
5. 실제 Play Data safety/Data deletion 답변과 개인정보처리방침을 함께 검토. 이 문서는 최종 법률·정책 판단이 아닙니다.
